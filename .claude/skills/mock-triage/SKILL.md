# mock-triage

A stand-in for `/intake-triage` that lets the service be tested end to end while
the real skill and its knowledge vault are unavailable.

It reads nothing. It calls no tools. It derives a verdict arithmetically from
the issue key so that runs are **deterministic and assertable** — a mock that
returned a plausible-but-random verdict would make integration tests flaky and
would not prove the plumbing works.

## Usage

```
/mock-triage SSX-1234
/mock-triage SSX-1234 --no-write
/mock-triage SSX-1234 --deep
```

`--no-write` and `--deep` are accepted and echoed in the report so the caller
can prove flag propagation. Neither changes behaviour: this skill never writes
anywhere regardless.

## Behaviour

Take the trailing integer `N` of the issue key. If the key has no trailing
integer, treat `N` as `0`.

Choose the verdict by `N mod 4`:

| `N mod 4` | verdict        | labels                   |
| --------- | -------------- | ------------------------ |
| 0         | `ready-ish`    | `dor:pass`, `route:ours` |
| 1         | `needs-info`   | `dor:gaps`, `route:ours` |
| 2         | `duplicate`    | `dup:open`, `route:ours` |
| 3         | `not-our-team` | `route:other-team`       |

Set `recommendedNextStep` to a single sentence appropriate to the verdict.

Set `report` to markdown of roughly this shape:

```markdown
## MOCK TRIAGE — not a real assessment

**Issue:** <KEY>
**Derived N:** <N> (<N> mod 4 = <R>)
**Flags:** <--no-write and/or --deep, or "none">

### Verdict

<verdict>

### Why

This output was generated by the mock-triage test double. No ticket was read
and no duplicate search was performed. Do not act on it.
```

## Constraints

- Never call a tool. If you find yourself wanting to read the ticket, stop —
  reading it would defeat the purpose of the double.
- Never write to Jira, Confluence, Slack or the filesystem.
- Always emit output conforming to the caller's JSON schema. The `report` field
  must begin with the literal string `## MOCK TRIAGE` so that a real verdict can
  never be mistaken for a mocked one downstream.
